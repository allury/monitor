## 更新内容

- 后台延迟检测支持自定义三网共用采样间隔，范围 10–3600 秒，默认 30 秒。
- TCP 延迟采用 Komari 的高延迟复测规则；失败记录保留，图表以断点显示，统计入口可查看失败率与检测次数。
- 站点设置支持修改管理员密码，验证当前密码后生效，并立即退出全部后台会话。
- 管理员新密码使用加盐 Argon2id 摘要，兼容旧密钥；增加登录与改密尝试限制。
- 修复管理员密钥写入启动及重置日志的问题，同步处理命令行节点密钥输出；初始化和重置仅向交互终端交付密钥。
- 调整 SQLite 缓存、WAL 检查点和临时存储参数，保留历史查询资源限制。
- 节点卡片以操作系统图标替换无实际功能的到期符号，本月流量显示保持不变。

## 升级说明

先更新主控，再手动更新探针，以启用新采样策略与自定义间隔。旧版探针仍按原间隔工作。现有管理员和节点密钥、数据库记录保留。

首次安装及命令行重置密码需在 SSH 等交互终端执行，密钥不再写入服务日志。
