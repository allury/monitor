# v0.4.1 安全与回归审验

审查日期：2026-09-04。基线：v0.4.0。范围为 Rust 主控、Linux Agent、前端改动、安装脚本和锁定依赖；不涉及线上服务器操作。

## 修复与加固

- 后台节点创建、令牌轮换、停用和设置保存：授权后的数据库写入与内存更新现在由独立任务完整执行，避免 HTTP 请求取消后，阻塞数据库任务已落盘而内存仍保留旧状态。新增取消请求回归测试。
- 探针安装：不再直接覆盖可能权限过宽的既有密钥文件。通过 `/etc` 下私有临时目录生成 root 所有的 0600 文件后原子替换，并拒绝符号链接或非普通文件。纯更新路径仍不读取或改写密钥。
- 探针认证头标记为敏感值，避免通用 HeaderValue 调试输出带出认证内容。
- 新增合图未放宽 CSP、未引入外部图表库或外部资源；动态尺寸使用受允许的 CSS 属性赋值，不使用内联样式字符串。

## 检查项目

- 管理员密码：带盐 Argon2id、旧摘要兼容、全局尝试预算、验证并发限制、改密后撤销会话。
- 节点身份：常量时间令牌校验、升级握手后二次检查、轮换/停用关闭旧连接、落盘前核验队列事件身份。公开接口不返回明文令牌或摘要。
- 输入与资源：HTTP/WS 消息上限、上报频率、历史范围与查询并发；字符串长度、非有限数值、延迟与采样参数边界；SQL 参数绑定与事务。
- Linux Agent：`statvfs`/`uname` 的 unsafe 边界仅在系统调用成功后读取初始化缓冲区；无远程执行、文件写入或自动更新入口。低权限 systemd 沙箱未放宽。
- 前端：不将失败补零或连线；平滑仅限制绘图视窗，选点保留原始值；图例、时间窗口、选点与自动刷新状态隔离；资源图原子替换、忽略仅高度变化的 resize。
- 安装：架构匹配、下载 SHA-256 校验、更新失败回滚与配置保留；密钥文件权限及符号链接拒绝回归。

## 依赖检查

使用 [RustSec cargo-audit 0.22.2](https://github.com/rustsec/rustsec/releases/tag/cargo-audit/v0.22.2)，工具附件 SHA-256 已核对。官方 [advisory-db](https://github.com/RustSec/advisory-db/tree/5a0ebedfe8bdd2e295b171f4162f8c977bcad9a5) 共 1239 条公告，对 Cargo.lock 的 166 个依赖检查：0 条已登记漏洞、0 条审计警告，无忽略规则。本地扫描未检查 yanked；CI 另执行不带排除项的 `cargo audit --deny warnings`。

CI 保留 Rustfmt、Clippy、全特性 Rust 测试、JavaScript/安装脚本回归、只读沙箱、真实主控与 Agent 集成，以及 GitHub CodeQL 扫描。实际检查结果以对应提交的 Actions 为准，源码修改不等于已发布。

这不是“零漏洞”保证，也不覆盖公网渗透测试、DDoS 防护或主机自身配置。HTTP 临时测试仍是明文传输；正式凭据应通过 HTTPS 使用。
