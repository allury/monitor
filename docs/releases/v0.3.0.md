## 新增

- 后台节点“安装 / 更新”入口，支持独立复制探针更新命令。
- 探针安装脚本支持 `--update`，保留原上报地址、密钥和服务配置；启动失败时回滚程序。
- 首页实时网速趋势，以及详情图表的指示线、选点读数、点击固定和键盘操作。
- 首页、节点详情与后台之间的无刷新导航，支持浏览器前进和后退。

## 优化

- 调整顶部导航、四项概览与桌面四列节点网格，完善窄屏和明暗主题布局。
- 精简节点系统名称，统一资源百分比及容量、网速和累计流量单位。
- 保留节点卡片“本月流量”的标签、单位、总量及上下行明细。
- 简化图表浮层，正常检测不显示失败计数，异常和缺失记录仍可区分。
- 页脚默认留空，后台仍可设置自定义内容。
- 移除页面右下角的更新时间状态，保留节点在线、离线及数据过期标识。

## 修复

- 修复未持有明文密钥时无法获取探针更新命令的问题，节点详情请求失败时仍保留更新入口。
- 管理员节点详情明确返回密钥保存状态；兼容前端已有密钥字段，不向公开接口暴露凭据。
- 切换页面时清理旧连接、请求和临时密钥，避免重复请求和过期响应覆盖当前页面。

## 升级说明

- 更新主控后，可在后台使用新的探针更新入口，无需重置已有节点密钥。
- 主控仍仅保存密钥摘要，无法恢复旧密钥明文；首次安装到新机器且未保留密钥时，需重置后使用完整安装命令。
- 保留现有数据库与配置，升级前请备份主控数据库。
